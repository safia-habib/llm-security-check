Scan your application

Paste the URL of an app you own. The scanner crawls its public surface, finds exposed LLM provider keys and common architecture mistakes, and explains what an attacker could do with each finding.

Passive scan only. This tool sends read-only requests (GET and HEAD). It never submits forms, never sends prompts to discovered AI endpoints, and never tests or stores discovered keys. A clean report is not a guarantee of security — see the footer for what cannot be checked.
